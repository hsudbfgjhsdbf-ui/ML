## 14.1 User Roles & Interface Capabilities
The interactive web application accessible on `http://0.0.0.0:8000` supports three distinct roles:

1. **Claimant / Policyholder:**
   - Multi-step claim submission wizard.
   - Document upload with real-time preview of OCR parsed bills and discharge summaries.
   - Transparent, plain-language adjudication verdict in English and Hindi (`फैसले का विवरण`).
2. **Claims Auditor / Investigator:**
   - Detailed multi-agent audit breakdown showing RAG policy clause citations, tariff variances, and historical velocity scores.
   - Human-in-the-loop checkpoint for flagged claims.
3. **Executive / Administrator:**
   - Full comparative benchmarking suite across all 22+ models.
   - Visual analytics gallery of ROC/PR curves and feature importances.
   - RAG knowledge base search interface.
