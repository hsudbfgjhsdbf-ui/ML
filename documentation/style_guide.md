# Style guide

**Purpose:** enforce consistent charts and formal academic communications. **Owner:** project team.  
**Last updated:** 06-08-2026.

- Palette: teal `#006D77` for primary information, orange `#E76F51` for fraud/risk, neutral grey for reference.
- Use colourblind-safe redundant labels; never rely on colour alone.
- Figures require title, labelled axes, units, data-scope caption, and minimum 150 DPI export.
- Metrics use four decimals; percentages use one decimal; narrative INR uses Indian grouping.
- Dates use DD-MM-YYYY. Claimants are described respectfully and scores are never accusations.
