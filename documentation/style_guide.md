# Visual and writing style guide

- Palette: navy `#102A43` for headings and structure; teal `#2A9D8F` for legitimate/neutral evidence; orange `#E76F51` for fraud-risk evidence; gold `#E9C46A` for emphasis; slate `#486581` for secondary text.
- Class semantics: teal means Legitimate; orange means Fraud. The legend always states this mapping.
- Figures use DejaVu Sans, light major gridlines, labelled axes, units, and a caption in documentation.
- Monetary values in prose use Indian Rupee notation such as `₹1,50,000`; source units are not invented when provenance is unknown.
- Dates in human-facing documents use `DD-MM-YYYY`.
- Metrics are rounded to four decimals in tables and one decimal place for percentages.
- Claims say “on this dataset under this protocol” rather than making universal performance claims.
- Explanations are neutral, evidence-led, and never assert claimant intent.
- AI-generated concept images are labelled as conceptual and never presented as measured results.
