SECTION 3 — DEEP LEARNING ARCHITECTURE DESIGNS
================================================================================

Architecture 1 - MLP: Multiple fully connected layers with ReLU, batch norm, dropout.
Architecture 2 - Wide and Deep: Linear model for memorization plus deep network.
Architecture 3 - DCN: Cross network for explicit feature interactions plus deep net.
Architecture 4 - TabNet: Sequential attention for feature selection on tabular data.
Architecture 5 - Transformer: Self-attention treating features as tokens.
Architecture 6 - ResNet: Residual blocks with skip connections for deep networks.
Architecture 7 - NODE: Differentiable oblivious decision trees as neural layers.
Architecture 8 - LSTM: Sequential claim modeling for policyholder history.
Architecture 9 - Autoencoder: Unsupervised anomaly detection via reconstruction.
Architecture 10 - VAE: Probabilistic latent space for generation and detection.

SECTION 4 — NETWORK LAYER SPECIFICATIONS
================================================================================

MLP: 3-5 hidden layers (256,128,64,32,16) with ReLU, batch norm, dropout 0.3.
Wide and Deep: Wide linear plus 3-layer deep (128,64,32) concatenated output.
Transformer: Feature embeddings, 2-4 encoder layers, 4-8 attention heads.
ResNet: Stacked residual blocks with pre-activation batch normalization.
TabNet: Attention transformer, feature transformer, multi-step aggregation.
NODE: Differentiable trees with temperature-controlled soft decisions.
LSTM: Variable-length sequences with hidden state capturing claim history.
Autoencoder: Encoder-bottleneck-decoder trained on legitimate claims only.
VAE: Encoder outputs distribution, reparameterization trick, KL divergence.
All architectures end with sigmoid output for binary classification.

SECTION 5 — ACTIVATION FUNCTIONS
================================================================================

ReLU: max(0,x), default for hidden layers, may have dead neurons.
Leaky ReLU: Small negative slope prevents dead neurons.
GELU: Smooth activation used in transformers, x times CDF of normal.
Swish/SiLU: x times sigmoid(x), smooth non-monotonic activation.
Sigmoid: Output layer activation producing fraud probability 0 to 1.
Softmax: For multi-class fraud type classification output.
Activation choice impacts gradient flow and training dynamics.
Multiple activations should be evaluated for each architecture.
GELU preferred for transformer architectures.
ReLU with He initialization works well for standard networks.

SECTION 6 — NORMALIZATION STRATEGIES
================================================================================

Batch normalization: Normalizes within mini-batch, enables higher learning rates.
Layer normalization: Normalizes across features, used in transformers.
Pre-normalization before attention improves transformer training stability.
Group normalization: Alternative for small batch sizes.
Ghost batch normalization in TabNet for small effective batch sizes.
Normalization placement affects training dynamics significantly.
Running statistics used during inference for batch normalization.
Normalization provides regularization effect preventing overfitting.

SECTION 7 — REGULARIZATION TECHNIQUES
================================================================================

Dropout: Random neuron deactivation preventing co-adaptation, rate 0.1 to 0.5.
L1 regularization: Promotes weight sparsity for implicit feature selection.
L2 regularization: Prevents large weights, weight decay in optimizers.
Early stopping: Monitors validation loss with patience 15-30 epochs.
Label smoothing: Replaces hard labels with 0.05/0.95 for calibration.
Gradient clipping: Maximum norm 1.0 prevents exploding gradients.
Data augmentation: Increases effective training set size.
Combination of techniques typically outperforms any single method.

SECTION 8 — OPTIMIZATION STRATEGIES
================================================================================

Adam: Adaptive learning rates with beta1=0.9, beta2=0.999 default.
AdamW: Decoupled weight decay with better generalization.
Cosine annealing: Gradual learning rate reduction following cosine curve.
Warm-up: Linear increase from small LR before cosine decay begins.
Learning rate finding: Exponential search for optimal initial LR.
Mixed precision: float16 computation with float32 master weights.
SGD with momentum: Simpler but requires careful LR tuning.
Optimizer comparison should be empirical for each architecture.

SECTION 9 — LOSS FUNCTIONS
================================================================================

Binary cross-entropy: Standard loss for binary classification.
Weighted BCE: Higher weight for minority fraud class.
Focal loss: (1-p)^gamma modulates CE, focusing on hard examples.
Combined focal plus class weighting for strongest imbalance handling.
MSE reconstruction loss for autoencoder architectures.
KL divergence for VAE latent space regularization.
Multi-task loss combines fraud classification with auxiliary tasks.
Loss function choice significantly impacts model performance.

SECTION 10 — BATCH SIZE AND TRAINING DYNAMICS
================================================================================

Small batches (16,32): Noisy gradients, better generalization.
Large batches (256,512): Stable gradients, may generalize worse.
Class-balanced sampling: Equal fraud/legitimate per batch.
Early stopping patience 15-30 epochs based on validation loss.
Gradient accumulation for effective batch size exceeding memory.
Training epochs determined dynamically by early stopping.
Learning rate schedule interacts with batch size selection.

SECTION 11 — WEIGHT INITIALIZATION
================================================================================

He/Kaiming initialization for ReLU: Variance 2/fan_in.
Xavier initialization for sigmoid/tanh: Variance 2/(fan_in+fan_out).
Transformer: Normal distribution with std 0.02.
Biases initialized to zero throughout all architectures.
Layer norm: Weight ones, bias zeros initialization.
Proper initialization critical for deep network training success.
