## FastAPI Example (optional)

```python
from fastapi import FastAPI
from pydantic import BaseModel
from typing import List, Dict, Any
from pathlib import Path
import sys
sys.path.insert(0, str(Path(__file__).parent.parent))
from approaches.06_hybrid_end_to_end import HybridFraudDetectionSystem
from common.config import load_config

app = FastAPI()
config = load_config(Path(__file__).parent.parent / "config.yaml")
system = HybridFraudDetectionSystem(config)

class ClaimRequest(BaseModel):
    ClaimID: str
    ClaimAmount: float
    ClaimDate: str
    DiagnosisCode: str
    ProcedureCode: str
    PatientAge: int
    PatientGender: str
    ProviderSpecialty: str
    PatientIncome: float
    ProviderLocation: str
    ClaimType: str
    ClaimSubmissionMethod: str
    Cluster: int
    Documents: List[Dict[str, str]] = []

@app.get("/health")
def health():
    return {"status":"ok","model_version": system.model_version}

@app.post("/predict")
def predict(req: ClaimRequest):
    claim_dict = req.dict()
    result = system.process_claim(claim_dict)
    return result

# Run: uvicorn api.main:app --host 0.0.0.0 --port 8000
```

## Security
- No API keys in code, use .env
- ENABLE_EXTERNAL_API_CALLS=false by default
- ANONYMIZE_PII=true

## Frontend Integration (Next.js)
- Frontend collects claim form + uploads docs (hashed, not raw PHI externally unless enabled)
- POST /predict
- Display risk category color, explanation, key risks, positive evidence, missing info, doc validation, evidence refs, timestamp, disclaimer
- Mandatory human reviewer checkbox for REJECT_OR_ESCALATE
- Appeal mechanism

```bash
curl -X POST http://localhost:8000/predict -H "Content-Type: application/json" -d @api/sample_request.json
```
