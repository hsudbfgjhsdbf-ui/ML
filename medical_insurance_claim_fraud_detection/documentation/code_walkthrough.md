## Common/
Reusable utilities:
- `config.py`: load_config YAML + env override
- `logging_utils.py`: get_logger
- `seed.py`: set_global_seed for py, numpy, torch, tf
- `dataset_loader.py`: load_claims_dataset, validate_schema, preprocess_target, get_feature_types, save_processed
- `schema_validation.py`: check_required, missing, imbalance, leakage detection heuristics, validate_claim_result_schema
- `preprocessing.py`: build_preprocessor (ColumnTransformer), engineer_date_features, outlier_analysis
- `metrics.py`: compute_all_metrics, precision_at_k, recall_at_k, threshold_analysis, calibration_curve_data
- `threshold.py`: select_threshold strategies
- `explainability.py`: get_feature_importance, shap_explain, generate_human_explanation
- `artifacts.py`: save_model, load_model, save_json
- `serialization.py`: safe_json_dump with numpy, pandas handling
- `result_formatting.py`: format_claim_result, risk_category_from_prob, decision_from_prob_and_rules, DISCLAIMER

## Approaches/
- `01_traditional_ml.py`: Full supervised workflow, benchmarks many classifiers, CV, calibration, threshold, SHAP, saves best model, writes evaluation/*.csv/md/json
- `02_deep_learning.py`: Tabular MLP via torch if available else sklearn MLP fallback, class-weighted, early stopping, LR scheduling, loss curves, threshold tuning, checkpoint saving, notes when DL underperforms tree models
- `03_anomaly_detection.py`: IsolationForest, LOF, OneClassSVM, EllipticEnvelope, Autoencoder optional, ensemble avg, metrics Prec@k, Rec@k, distinction anomaly vs fraud prob
- `04_document_intelligence.py`: OCR via Tesseract/EasyOCR/PaddleOCR/fallback, VLM optional interface env-controlled, type identification, field extraction regex+structured, validation (bill total, date consistency, provider, policyholder, duplicate, missing), structured JSON output with confidence
- `05_agentic_rag_reasoning.py`: KnowledgeBase (chunk, TFIDF fallback or sentence-transformers), EvidenceRetrievalAgent, 7 agents, DecisionSynthesisAgent, ExplanationGenerationAgent, grounded auditable summary, LLM optional deterministic fallback
- `06_hybrid_end_to_end.py`: Combines best ML, anomaly, doc validation, RAG, explainability, outputs final structured result with 3 operational outcomes, conservative manual review zone, threshold documented
